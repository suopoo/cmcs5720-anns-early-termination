# 实验一：特征迁移消融研究报告（中文）

## 实验设置

GIST1M（索引 992,000 条、960 维），k=10，目标 Recall
0.9，统一预测点 f=1,260 NDC；训练 5,000 /
验证 500 / 测试 1,000 条互不重叠的 Query。六个实验组只改变输入特征，
预测目标、损失函数、训练数据、预测时机和终止规则全部固定。DARTH 的
D1 与 D2 在去重后完全相同，因为 DARTH 的 11 个特征本来就是 ANNiE
basic 特征块的子集；这是结构事实，不是实验结论。

## 配对统计与假设

| 假设 | 证据（配对 95% CI） |

| H1c：L1 明显优于 L2（原特征有互补信息） | inconclusive (mean Δ=-0.0248, 95% CI [-0.0539, +0.0066]) |

## 解释

预测精度的变化与端到端搜索收益必须分开判断。即使某个迁移组的平均
误差下降，若 NDC 或达标率没有同向变化，也不能声称端到端变好；反之，
图结构特征的提取开销也必须计入。所有结论均以 Query 级配对 Bootstrap
置信区间为准，不显著时写为“证据不足”。


## 最有价值的发现

1. **ANNiE 特征确实降低了 LAET 的代价预测误差，但没有转化为更好的搜索。**
   L1 的 Query 级 |log2 误差| 降低 0.072（相对 7.0%，配对 95% CI
   [-0.112, -0.031]）；但在验证集校准后的乘子下，搜索 Recall 反而下降
   1.32 个百分点（CI [-1.89, -0.74]），NDC 下降 275（CI [-418, -114]）。
   这说明预测精度与端到端质量是两个层面的结果，H3 得到支持。

2. **在 n=5,000 下，LAET 原始特征尾没有可测的互补信息。**
   L1 vs L2 的误差差为 -0.025，95% CI [-0.054, +0.007]，不显著；
   Gain importance 显示图特征并未被忽略（h-hop reachability 是 L1 的第一
   重要特征、D1 的第二重要特征）；L1 与 L2 的差异不显著更可能是因为两组
   特征对该标签高度冗余，而不是图特征没有信号。

3. **DARTH 的特征迁移是控制良好的“零结果”，而且代价很高。**
   D1/D2 在 Query 级 Recall 误差上与 D0 无显著差异（Δ=-0.00007，
   CI [-0.0016, +0.0016]）；D1 与 D2 因特征去重而完全相同。
   30 条 Query 的实测端到端延迟：D0 66 ms，D1/D2 183 ms（约 2.8 倍），
   因为每个 checkpoint 都要重新提取图特征。

4. **延长预搜索不能挽救迁移效果。** 在 f ∈ {256,512,1260,2048} 上重训
   L0/D0，命中率曲线在配对不确定度内基本平坦。
## 局限

Python 实现、992k 索引规模、5,000 条训练 Query、ANNiE 局部子图的 Def.7
近似、以及只在 f=1,260 对 L1/L2、D1/D2 做完整比较，都会限制结论的外推。
